# PBFM Terrain Phase 2

Phase 2 resumes the existing PBFM run from global environment step 99,295,232
with a harder fixed terrain distribution. This is an intentional training
distribution shift; it is not a curriculum manager.

| Setting | Phase 1 | Phase 2 |
| --- | ---: | ---: |
| Flat proportion | 0.40 | 0.20 |
| Slope proportion | 0.25 | 0.20 |
| Stairs proportion | 0.10 | 0.30 |
| Rough proportion | 0.25 | 0.30 |
| Stair levels | 4 | 20 |
| Stair depth | 0.30 m | 0.30 m |
| Stair height range | 0.08-0.11 m | 0.08-0.15 m |
| Stair transition width | 3.9 m | 13.5 m |

At 1024 environments per rank, MJLab's proportional allocation gives 205 flat,
205 slope, 307 stairs, and 307 rough environments. At eight ranks the global
counts are 1639, 1639, 2457, and 2457 respectively.

The network architecture, observation schema, canonicalization, optimizer
state, replay state, LaFAN data, and fixed-flat EMD priority evaluator remain
unchanged. The restored replay initially contains phase-1 samples, so the
effective replay distribution transitions gradually after resume.
